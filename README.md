# MyMCATstudyguide.com

Sarah's MCAT flashcard site. The whole website is one file, `index.html`.

## Files

| File | What it is |
|---|---|
| `index.html` | The website (required) |
| `3-2020_whats_on_the_mcat_content_outline.pdf` | Opened by the "What's on the MCAT?" button (required) |
| `README.md` | This file |
| `docs/` | Reference files for you: master card list (`flashcards.csv`), card ID registry, scheduling rules, changelog, test report, known limitations. The site doesn't use them. |

## Vercel settings
- Framework Preset: **Other**
- Root Directory: **./** (the repo root)
- No build command

## Later
- Help video: upload `how-to-use-me.mp4` (and optional captions `how-to-use-me.vtt`) to the repo root. The How to Use Me popup picks it up.
- Progress is saved in Sarah's browser, not in this repo, so changing or re-uploading files never erases it.
